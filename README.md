# ClaimFlux SA

AI-powered South African appliance warranty and CPA claim assistant.

## Features

- Receipt scanning
- AI extraction
- Warranty matching
- CPA eligibility checker
- Claim generation
- Dashboard tracking
- Email login

## Tech Stack

- Flask
- OpenAI GPT-4o
- Supabase
- HTML/CSS/JS

## Run locally

pip install -r requirements.txt

python app.py
